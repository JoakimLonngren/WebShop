A backend Web Api for a webshop build with ASP.Net Core 8.0 using EF Core and Identity. Secure user registration, and JWT-based authentication. Versioned for future potential versions and documented with Swagger.

Features added up to this point

* Register and Login
* Authentication and Authorization with Identity and JsonWebTokens.
* Usermanagement with extention of IdentityUser in ApplicationUser for potential shipping possibility in the future.
* Built with layer-structure (repository, service and controllers) and api-first in mind.

Tech-stack
* Asp.Net Core 8.0 (WebApi)
* Asp.Net Identity 
* Entity Framework Core (Code-first)
* SQL-server based
* Swagger/OpenApi
